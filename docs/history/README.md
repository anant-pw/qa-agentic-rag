# Project history

These files were moved here from the repository root on 2026-10-05 to keep the root readable. Nothing in them was changed.

| File | What it is |
|---|---|
| `phase-01-handoff.md` … `phase-08-handoff.md` | One handoff per phase: what was built, design decisions and why, bugs found, real measured numbers, known limitations. **`phase-08-handoff.md` is the final state of the project.** |
| `PHASE5_VERIFY.md`, `PHASE6_VERIFY.md` | Manual verification notes for Phases 5 and 6 |
| `KNOWN_LIMITATIONS_generation.md` | Generation limitations recorded during Phase 5/6 |
| `verify_phase3.sh`, `verify_phase4.sh` | Acceptance checks for Phases 3 and 4. They assert counts for the original 28-document corpus, so they do not match the current 173-document corpus. |
| `phase3_query_results_TEMPLATE.md` | Recorded Phase 3 search results (filled in, despite the name) |
| `manual4.txt` | A manual evaluation transcript from Phase 6/7 |

Code comments and older documents (for example `docs/PROJECT_LOG.md`) refer to these files by their bare names, such as `phase-02-handoff.md`. They now live in this folder.
