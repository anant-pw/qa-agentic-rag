# TC-0301: Search tokenization consistency for hyphenated terms

**Module:** Search

## Preconditions
Product catalog contains items with both 'wifi' and 'wi-fi' spellings in titles or descriptions.

## Steps
1. Search for 'wifi'
2. Note the result count and items returned
3. Clear search, search for 'wi-fi'
4. Compare result count and items returned to step 2

## Expected Result
Both queries should return the same (or substantially overlapping) result set, since they represent the same search intent. A hyphen should not cause tokenization to diverge between index time and query time.
